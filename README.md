A tiny stack virtual machine: a byte-exact interpreter of make.fun's tiny stack ISA v1 (32-bit wrapping arithmetic, 256-value stack, calls, 256 words of memory, input/output, all ten traps with their own exit codes). One run answers every instance of the set.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
